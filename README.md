Sales Data Analysis – Power BI

Project Overview

This project focuses on analyzing sales data using Microsoft Power BI. The objective is to clean raw sales data, create meaningful visualizations, and generate business insights using DAX calculations.

Tools Used

Microsoft Power BI

Power Query

DAX (Data Analysis Expressions)

Data Cleaning

Handled missing values.

Removed duplicate records.

Standardized date formats.

Prepared and loaded the cleaned dataset into Power BI.

Dashboard & Analysis

Regional Analysis: Pie chart showing order distribution across regions.

Top 5 Products: Column chart displaying the most frequently ordered products.

Profit Trend: Line chart showing profit trends over time.

DAX Calculations

Created a calculated table: EastRegionOrders.

Created a calculated column: ProfitCostDifference.

Created a measure: TotalProfit.
